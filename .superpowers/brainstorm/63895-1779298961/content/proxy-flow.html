Edge case: proxy only
If Rosa is only picking up for others, her own family card appears unchecked. She simply skips it and confirms only the proxy families.

Data model: how this works

  • Each family record carries a list of authorized proxy phone numbers (already in Bubble.io data)
  • Lookup queries in both directions: families where picker's phone = primary, AND families where picker's phone is in the proxy list
  • Each confirmed visit logs: family ID + date + picked up by (self or proxy phone)
  • New proxy relationships added via the existing proxy forms flow (preserved from Bubble.io)
