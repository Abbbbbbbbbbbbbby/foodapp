What changed

  • Self-registration: Volunteers can create their own account with name + phone. Name is required for identification. Admins can still pre-create accounts for staff/admin roles.
  • Proxy form deferred: /enter/proxy-forms page removed from scope. Proxy data model kept; proxy relationships still surface at check-in. UI for adding new authorizations is TBD.
  • Data summary page: New /data/summary page (staff + admin) with date range selector, totals, AMI bracket chart, ethnicity/language/SNAP/insurance/zip breakdowns, visits over time.
  • Step 0 question: Now reads "Have we saved your data before?" / "¿Hemos guardado sus datos antes?" — appropriate for a system migration context.
  • No "read aloud" labels: Both EN and ES sentences shown at equal size with no directional markers. Volunteer reads whichever fits.
  • Duplicate detection: If name or phone entered during new registration matches an existing record, app surfaces a confirmation card before continuing.
  • Proxy captured first: Before the 11-step wizard, new families are asked who usually picks up for them. Answer saved to proxies table. "They pick up for themselves" skips it.
  • Decline phrasing: "Can't answer" replaced throughout with "Prefer not to say / Prefiero no responder."
  • Household size 7+: Buttons go 1–7; tapping 7+ shows a numeric input for exact count.
  • Income question overhauled: Asks pay period (weekly / every 2 weeks / monthly / yearly / prefer not to say), then amount. App silently calculates AMI bracket using Maricopa County thresholds — only bracket stored, raw income discarded.
  • Text messages split into two steps: 11a asks if they currently receive texts; 11b (only shown if yes) asks if they want food distribution updates. Yes to 11b triggers Twilio SMS enrollment.
