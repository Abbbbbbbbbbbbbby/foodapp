A — One question at a time Recommended

Each screen shows a single field with large tap targets. Big buttons for Yes/No/counts, numeric keypad for numbers, minimal typing. Progress bar shows where you are. Back/Skip always visible.

Pros

  • Easiest for older users — no clutter
  • Large tap targets, impossible to miss
  • Clear bilingual label per question
  • Very hard to accidentally skip a field

Cons

  • More screens = more taps per family
  • Experienced volunteers may find it slow

B — Grouped sections (3–4 fields per screen)

Fields grouped into logical sections: Family Info, Demographics, Benefits. Each section fits on one screen without scrolling. Faster for confident volunteers; still manageable for beginners.

Pros

  • Fewer screen transitions
  • Context stays visible (name + phone together)

Cons

  • More crowded — harder for older eyes
  • Touch targets smaller
  • Easy to miss a field

C — Single scrollable form

All fields on one long page, similar to the existing Bubble.io layout. Familiar pattern for web users. Volunteers who know the form can move fast by scrolling.

Pros

  • Familiar to anyone who's used a web form
  • Can see and edit everything at once

Cons

  • Worst for older users — tiny fields, easy to scroll past
  • Hard to track what's filled vs. skipped
  • Not mobile-first by nature

I strongly recommend A for this community — large targets, one focus at a time, impossible to feel lost. It can be made fast once volunteers know the flow.
